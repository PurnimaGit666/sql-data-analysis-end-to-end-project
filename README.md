# SQL Project For Data Analysis - End To End Project

This is an End-to-End SQL Portfolio Project for Data Analysis.

### Tools Used
- MySQL
- SQL
- GitHub

### Topics Covered
- Basic SQL Queries - SELECT, WHERE, ORDER BY
- Aggregate Functions - COUNT, SUM, AVG
- GROUP BY & HAVING
- JOINS - INNER, LEFT, RIGHT
- Subqueries
- Window Functions - RANK, ROW_NUMBER
- CTEs

### Business Questions Solved
- Total Revenue, Total Orders
- Top Selling Products
- Category Wise Sales
- Customer Insights
- Monthly Sales Trend
